第一次使用，先拿到通行令牌

  1. 用管理员邀请的 GitHub 账号登录 github.com
  2. 打开 令牌设置页，点「Generate new token」
  3. 仓库范围选「Only select repositories」，只勾 liulianghuo/liulianghuo
  4. 权限里把 Contents 设为「Read and Write」，其余不动
  5. 生成后立刻复制，粘贴到左边输入框

令牌只存在你自己的浏览器里，不会写进网站，也不会发给第三方。别把令牌发给别人，别在公共电脑勾「记住我」。

使用帮助

运营只需要记住一个网址和四步操作

日常发布四步

  1. 打开 liulianghuo.com/admin/，用自己的令牌登录
  2. 点「写新文章」，填分类、标题、摘要、日期、正文
  3. 点「预览页面」确认排版，再点「发布到官网」
  4. 等 1～3 分钟，打开「行业观点」就能看到新文章排在最上面

改文章：列表里点「编辑」，改完再点「保存并发布」，网址不会变。不想展示：点「下线」，随时能恢复。

多个人一起用

管理员去 仓库协作者设置 邀请对方的 GitHub 账号，权限给 Write。每个人都用自己账号生成自己的令牌。

「发布记录」里能看到每一条操作是谁、什么时候做的，也能按账号统计。管理员还能在这里一键回滚到任意一次发布之前。

运营可以发布、修改、下线、恢复；删除文章和回滚历史只有管理员能操作。

要留意的事

  • 发布后官网要重新构建，通常 1～3 分钟生效，刚发布立刻打开文章链接可能暂时是空白页
  • 令牌只放在你自己的浏览器里，网站服务器上没有；换电脑要重新生成一次
  • 后台所在的仓库是公开的，草稿和文章内容在代码仓库里能被看到，不要写不适合公开的内容
  • 后台打不开、令牌过期或账号变动，官网照常访问，已发布的文章不会消失，只是暂时发不了新的
  • 不要在公共电脑勾选「记住我」，离开时点「退出」

对官网的影响

  • 首页、产品、案例、套餐、关于等页面：一个字都不改
  • 明暗主题、Logo、排版、页脚、样式和脚本：都不动
  • 老的 9 篇文章：原样保留，不进后台改删范围
  • 发一篇新文章，只会在「行业观点」列表顶部加一条，并同步加进站点地图
  • 文章是生成好的完整静态网页，百度和 AI 爬虫能直接读到全文
